## ✨ قابلیت‌های برجسته

<div dir="rtl">

- 🕶️ **کدهای مخفی خودحذف‌شونده** — کنترل کامل ربات از هر چتی با کدهای ۳ رقمی که بلافاصله پس از ارسال پاک می‌شوند.
- 🤖 **دو حالت اصلی** — حالت رفیق (لحن خودمانی شما) و حالت دستیار (منشی مودب ۲۴ ساعته)، با **دامنهٔ چت‌به‌چت یا سراسری**.
- 🎭 **موتور پرسونای نامحدود** — فایل متنی دلخواه در `personas/*.txt` بساز و بدون ریستارت لحن را عوض کن.
- 🕵️ **تعامل خودکار در گروه‌ها** — بررسی منظم گفتگوها و ورود طبیعی به بحث‌های جالب.
- ⚡ **شبیه‌ساز رفتار انسانی** — تأخیر خواندن، زمان تایپ متناسب با طول جواب تا ۴۵ ثانیه، مکس فکر کردن و تکه‌تکه فرستادن.
- 🌙 **ساعات خواب و ضدشناسایی** — شب‌ها ساکت می‌شود (`121`)، گاهی **غلط تایپی می‌فرستد و ویرایشش می‌کند**، گاهی فقط **ریاکشن می‌گذارد**، و هرگز ده نفر را در یک ثانیه جواب نمی‌دهد (`122`).
- 👁️ **درک چندرسانه‌ای** — عکس، ویس، ویدیونوت و ویدیو (تا ~۱۸ مگابایت) و فایل‌های PDF و متنی.
- 🧠 **حافظهٔ دو لایه** — ۳۰ پیام آخر با برش هوشمند جملات + خلاصه‌ساز پس‌زمینهٔ فکت‌های کلیدی.
- 🛡️ **استخر کلیدهای جمینای** — چرخش Round-Robin، سقف مصرف روزانه، کنترل نرخ درخواست و Circuit Breaker.
- 🧹 **پاکسازی روح** — حذف دسته‌ای تمام پیام‌های شما با مدیریت خودکار FloodWait.
- 🔌 **معماری افزونه‌ای** — مادول‌های رفتاری خودشان را نصب می‌کنند؛ `main.py` دست‌نخورده می‌ماند و خرابی یک افزونه ربات را نمی‌خواباند.

## 🎮 راهنمای کدهای رمزی و مخفی

> [!IMPORTANT]
> **امنیت اختصاصی مالک**: تمامی کدها تنها از طریق پیام‌های ارسالی خود شما معتبرند. به محض دریافت، **دستور فوراً حذف می‌شود** و تأیید آن موقتاً در «پیام‌های ذخیره‌شده» نمایش داده می‌شود.

<div dir="rtl">

| کد مخفی | محدوده | عملکرد |
| :--- | :---: | :--- |
| `777` / `777 <persona>` | چت جاری | **روشن کردن رفیق** (مانند `777 sarcastic`). |
| `000` / `000 all` | چت / سراسری | **خاموش کردن رفیق**. |
| `777 engage [دقیقه]` | گروه | **تعامل خودکار** (پیش‌فرض هر ۲۰ دقیقه). |
| `777 engage auto` | گروه | 🧠 **تعامل هوشمند**: سرعت گروه را می‌سنجد و فاصله را خودش تنظیم می‌کند. |
| `777 engage off [all]` | گروه / سراسری | **خاموش کردن تعامل خودکار**. |
| `666` | فقط همین چت | **دستیار فقط در چت جاری** روشن می‌شود. |
| `666 all` | تمام پیوی‌ها | **دستیار برای همهٔ پیوی‌ها** (فعلی و آینده). معادل‌ها: `666 کل`، `666 همه`. |
| `444` | چت جاری | **توقف دستیار فقط در این چت**. |
| `444 all` / `444 کل` | تمام پیوی‌ها | **خاموش کردن کامل دستیار**. |
| **`121`** | **سراسری** | 🆕 🌙 **ساعات خواب** — وضعیت، بازه، خواب/بیداری دستی، معافیت چت. |
| **`122`** | **سراسری** | 🆕 🧬 **رفتار انسانی** — غلط تایپی، ریاکشن به‌جای جواب، محدودکنندهٔ انفجار. |
| `!مسدود` (روی پیام) | سراسری | **لیست سیاه**: دستیار دیگر هرگز به این کاربر جواب نمی‌دهد. |
| `!آزاد` (روی پیام) | سراسری | **حذف کاربر از لیست سیاه**. |
| `!استیکر <توضیح>` | سراسری | 🎭 **آموزش استیکر**: روی استیکر ریپلای کن و معنی‌اش را بگو. |
| `!استیکر لیست` / `!استیکر حذف` | سراسری | 🎭 مدیریت استیکرهای آموزش‌دیده. |
| `222 [ساعت]` | گروه/پیوی | **خلاصه گفتگو**: ۱۲ ساعت گذشته (تا ۷۲ ساعت). |
| `112 <سوال>` | هرجا | **جستجوی وب** با گوگل (قیمت ارز، آب‌وهوا، اخبار). |
| `111 [دستور]` | ریپلای | **پاسخ هوشمند** به پیام ریپلای‌شده. |
| `555 <یادآور>` | چت جاری | **یادآور هوشمند**: `555 ساعت 21 به علی بگو تماس بگیره`. |
| `333` | چت جاری | **ریست حافظه** کوتاه‌مدت و بلندمدت. |
| `999 [تعداد]` | چت جاری | **پاکسازی روح**: حذف همه (یا N پیام آخر) پیام‌های شما. |
| `555` | چت جاری | **وضعیت زنده** با حذف خودکار. |
| `888` | چت جاری | **راهنما** و لیست کدهای مخفی. |

تأیید همهٔ دستورها و خطاهای موتور به «پیام‌های ذخیره‌شده» می‌رود و خودبه‌خود پاک می‌شود — هیچ ردی در چت مقصد نمی‌ماند.

وقتی حالت «رفیق» یا «دستیار» فعال باشد، ربات محتوای 📷 عکس، 🎙️ ویس، 🎬 ویدیو و 📄 فایل‌های PDF را می‌فهمد و طبیعی جواب می‌دهد.

## 🎯 دامنهٔ دستیار: `666` یا `666 all`

<div dir="rtl">

قبلاً دستیار یا در همه‌جا روشن بود یا هیچ‌جا. حالا دو لایه دارد تا بتوانی منشی را فقط برای یک نفر خاص بگذاری:

- `666` → فقط همان چتی که فرستادی.
- `666 all` → تمام پیوی‌ها، شامل کسانی که بعداً پیام می‌دهند.
- `666 <چیز دیگر>` → با هشدار رد می‌شود؛ یک غلط تایپی هرگز تو را بی‌سروصدا سراسری نمی‌کند.
- `444` → سکوت در این چت · `444 all` → خاموشی کامل.

داشبورد `555` دقیقاً می‌گوید کدام لایه فعال است و چند چت تک‌به‌تک روشن شده‌اند.

> [!WARNING]
> **مهاجرت یک‌باره.** فایل‌های وضعیت قدیمی در اولین اجرا ارتقا می‌یابند و دستیار **خاموش** می‌شود تا بی‌سروصدا به همهٔ پیوی‌ها جواب ندهد. بعد از آپدیت، در چت‌های دلخواه `666` بزن یا یک‌بار `666 all` بفرست. لیست سیاه دست‌نخورده می‌ماند.

</div>

## ⚡ شبیه‌ساز رفتار انسانی

<div dir="rtl">

بزرگ‌ترین نشانهٔ روبات بودن این نیست که *چه* می‌نویسد؛ این است که *چقدر سریع* می‌نویسد. یک پاراگراف ۴۰۰ کاراکتری که بعد از ۳ ثانیه بیاید، برای انگشت انسان غیرممکن است. پس کل خط لولهٔ ارسال انسانی‌سازی شده:

۱. **تأخیر خواندن متناسب** پیش از شروع تایپ.
۲. **زمان تایپ متناسب با طول متن** روی منحنی غیرخطی، با سقف **۴۵ ثانیه** جای سقف خشک ۷ ثانیه‌ای قدیم.
۳. **مکس‌های تصادفی فکر کردن** در میانهٔ تایپ، تا علامت typing مثل انسان روشن و خاموش شود.
۴. **تکه‌تکه فرستادن خودکار**: جواب‌های بلند از مرز جملات بریده و چند پیام جداگانه می‌شوند. کد و استیکر هرگز تکه نمی‌شوند.
۵. **پالایشگر خروجی ضد ربات**: حذف ایموجی، اعراب عربی، تگ HTML و لیست‌های مارک‌داون.

| طول جواب | زمان تایپ |
|---|---|
| ~۵ کاراکتر | ~۱.۲ ثانیه |
| ~۵۰ کاراکتر | ~۱۵ ثانیه |
| ~۱۵۰ کاراکتر | ~۵۰ ثانیه (تکه‌تکه می‌شود) |
| بیش از ۴۰۰ کاراکتر | سقف ۴۵ ثانیه برای هر حباب |

تمام این اعداد با متغیرهای `HUMAN_*` قابل تنظیم‌اند — [مرجع متغیرها](docs/CONFIG_FA.md).

</div>

## 🌙 ساعات خواب و رفتار ضدشناسایی

<div dir="rtl">

زمان‌بندی فقط نیمی از ماجراست. یک یوزربات که **۲۴ ساعته بیدار است**، **هرگز اشتباه نمی‌کند** و **ده نفر را در یک ثانیه جواب می‌دهد**، هنوز واضحاً ماشین است. دو افزونهٔ خودنصب دقیقاً این را حل می‌کنند و هر دو **زنده** قابل تنظیم‌اند — بدون نیاز به Redeploy.

### 🌙 ساعات خواب (`121`)

| دستور | کار |
|---|---|
| `121` | وضعیت: بازه، ساعت محلی ربات، چقدر تا بیداری |
| `121 01:00 09:00` | تنظیم بازهٔ خواب و روشن کردن |
| `121 on` / `121 off` | روشن / خاموش |
| `121 tz +03:30` | تنظیم منطقهٔ زمانی |
| `121 sleep 90` | همین الان ۹۰ دقیقه بخواب (مانند جلسه) |
| `121 wake 60` | ۶۰ دقیقه بیدار بمان، حتی در بازهٔ خواب |
| `121 now` | لغو خواب/بیداری دستی |
| `121 allow` | معاف کردن همین چت — شب‌ها هم جواب می‌گیرد |

فرمت ساعت انعطاف‌پذیر است: `23:30` یا `2330` یا `23`؛ ارقام فارسی هم قبول می‌شود و بازه‌های عبورکننده از نیمه‌شب درست کار می‌کنند.

> [!IMPORTANT]
> ساعات خواب فقط جلوی **جواب‌های خودکار** (رفیق، تعامل خودکار، دستیار) را می‌گیرد. **دستورهای خودت همیشه کار می‌کنند** — `111`، `112`، `222`، `555`، `999` ساعت ۴ صبح دقیقاً مثل وسط روز عمل می‌کنند.

### 🧬 رفتار انسانی (`122`)

۱. **غلط تایپی و تصحیح** — با احتمال کم، ربات جای دو حرف را عوض می‌کند یا حرفی را می‌اندازد، و چند ثانیه بعد یا **پیام را ویرایش می‌کند** (تلگرام برچسب `edited` را نشان می‌دهد — نشانهٔ بسیار انسانی) یا پیام `*کلمهٔ درست` می‌فرستد. لینک، منشن، عدد و جواب‌های چندخطی هرگز دستکاری نمی‌شوند.
۲. **ریاکشن به‌جای جواب** — وقتی جواب یک جملهٔ بی‌ارزش است (`خخخ`، `باشه`، `مرسی`) و ریپلای به پیامی خاص است، متن حذف می‌شود و ربات فقط **ایموجی متناسب می‌گذارد**. سوال‌ها همیشه متنی جواب داده می‌شوند؛ اگر ریاکشن ناموفق باشد، متن عادی فرستاده می‌شود.
۳. **محدودکنندهٔ انفجار** — سقف سراسری و فاصلهٔ حداقل بین جواب‌های خودکار، تا ده پیام ورودی ده جواب فوری تولید نکند.

| دستور | کار |
|---|---|
| `122` | وضعیت هر سه رفتار |
| `122 on` / `122 off` | روشن / خاموش کردن کل پکیج |
| `122 typo 8` | احتمال غلط تایپی (درصد) |
| `122 style edit\|star\|mixed` | سبک تصحیح غلط |
| `122 react 20` | احتمال ریاکشن به‌جای جواب (درصد) |
| `122 burst 3 60` | حداکثر ۳ جواب خودکار در ۶۰ ثانیه |
| `122 spacing 6` | حداقل ۶ ثانیه فاصله بین دو جواب |
| `122 reset` | بازگشت به پیش‌فرض‌ها |

هر دو مادول در انتهای `pal_manager.py` خودشان را نصب می‌کنند، پس **`main.py` اصلاً تغییر نکرده** و اگر افزونه‌ای لود نشود ربات فقط یک هشدار لاگ می‌کند و مثل قبل کار می‌کند. لاگ اولیه باید این دو خط را داشته باشد:

```
🌙 Quiet Hours ready — ❌ غیرفعال | کد 121
🧬 Human Behavior ready — ✅ غلط 8٪ | واکنش 22٪ | سقف 3/60ث
```

📖 مرجع کامل (همهٔ متغیرها، جدول ایموجی‌ها، خط لولهٔ ارسال و عیب‌یابی): [`docs/HUMANIZATION.md`](docs/HUMANIZATION.md)

## 🎭 حالت‌های هوش مصنوعی و پرسونا

<div dir="rtl">

**۱. حالت رفیق (Alter-Ego)** — با `777` ربات مثل خود شما رفتار می‌کند؛ لحن عامیانه، پاسخ کوتاه بدون ایموجی و ارجاع به سوابق گفتگو. در گروه‌ها فقط با ریپلای یا منشن جواب می‌دهد.

**۲. حالت دستیار** — با `666` برای یک چت و `666 all` برای همهٔ پیوی‌ها. نقش منشی موقر شما را بازی می‌کند و پیام می‌گیرد.

**۳. تعامل خودکار گروهی** — با `777 engage <دقیقه>` سوابق گروه را دوره‌ای بررسی می‌کند و اگر بحث جالبی در جریان باشد وارد می‌شود. `777 engage auto` فاصله را از سرعت واقعی گروه می‌سازد.

**۴. تعویض زندهٔ پرسونا** — هر فایل `.txt` در پوشهٔ `personas/` یک لحن جدید است: `normal`، `assistant`، `sarcastic`، `poetic`، `academic`، `angry`، `drunk`، `lust`.

> [!TIP]
> برای لحن جدید کافیست فایلی مانند `personas/gamer.txt` بسازی و با `777 gamer` فعالش کنی — بدون ریستارت!

## 🚀 راه‌اندازی

<div dir="rtl">

### روش اول: Railway (پیشنهادی برای ۲۴ ساعته)

۱. ریپو را فورک/کلون کن و یک سرویس Railway از روی آن بساز.
۲. یک **Volume** بساز و در `/app/data` وصل کن — بدون آن، حافظه، یادآورها و تنظیمات `121`/`122` با هر ری‌استارت پاک می‌شوند.
۳. `python3 gen_session_string.py` را **روی سیستم خودت** اجرا کن و خروجی را در `SESSION_STRING` بگذار.
۴. `API_ID`، `API_HASH`، `GEMINI_API_KEYS`، `OWNER_ID` را تنظیم کن و دیپلوی بزن.

> [!TIP]
> اگر Railway خطای **«GitHub Repo not found»** داد، اپ Railway دسترسی‌اش به ریپو را از دست داده. به <https://github.com/settings/installations> برو ← Railway ← دسترسی بده، سپس Source Repo را قطع و وصل کن و Redeploy بزن.

### روش دوم: نصب محلی

```bash
git clone https://github.com/parhambepe/ghostali.git
cd ghostali
python -m venv venv
source venv/bin/activate   # در ویندوز: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
python login.py
python main.py
```

### روش سوم: داکر

```bash
docker compose up -d --build
docker compose logs -f
```

### روش چهارم: ویندوز و VPS

روی ویندوز `setup.bat` (یا `python setup.py`) ویزارد نصب را اجرا می‌کند. اسکریپت‌های `deploy.bat` و `deploy.sh` هم پروژه را روی سرور لینوکس به عنوان سرویس `systemd` مستقر می‌کنند (کافیست `VPS_IP`، `SSH_USER`، `SSH_PORT` در `.env` پر شود).
