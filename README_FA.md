## ✨ قابلیت‌های برجسته

<div dir="rtl">

- 🕶️ **کدهای مخفی خودحذف‌شونده** — کنترل کامل ربات از هر چتی با کدهای ۳ رقمی که بلافاصله پس از ارسال پاک می‌شوند.
- 🤖 **دو حالت اصلی هوش مصنوعی** — حالت رفیق (لحن خودمانی شما) و حالت دستیار (منشی مودب ۲۴ ساعته)، حالا با **دامنهٔ چت‌به‌چت یا سراسری**.
- 🎭 **موتور پرسونای نامحدود** — فایل متنی دلخواه در `personas/*.txt` بساز و بدون ریستارت لحن را عوض کن.
- 🕵️ **تعامل خودکار در گروه‌ها** — بررسی منطم گفتگوها و ورود طبیعی به بحث‌های جالب در فواصل تصادفی.
- ⚡ **شبیه‌ساز رفتار انسانی** — تاخیر خواندن متناسب، زمان تایپ متناسب با طول جواب تا ۴۵ ثانیه، مکث فکر کردن و تکه‌تکه فرستادن جواب‌های بلند.
- 👁️ **درک چندرسانه‌ای** — عکس، ویس، ویدیونوت و ویدیو (تا ~۱۸ مگابایت) و فایل‌های PDF و متنی.
- 🧠 **حافطه دو لایه** — ۳۰ پیام آخر با برش هوشمند جملات + خلاصه‌ساز پس‌زمینهٔ فکت‌های کلیدی.
- 🛡️ **استخر کلیدهای جمینای** — چرخش Round-Robin، سقف مصرف روزانه، کنترل نرخ درخواست و Circuit Breaker.
- 🧹 **پاکسازی روح** — حذف دسته‌ای تمام پیام‌های شما با مدیریت خودکار FloodWait.

## 🎮 راهنمای کدهای رمزی و مخفی

> [!IMPORTANT]
> **امنیت اختصاصی مالک**: تمامی کدهای رمزی تنها از طریق پیام‌های ارسالی خود شما معتبرند. به محض دریافت، **دستور فوراً حذف می‌شود** و تأیید آن موقتاً در «پیام‌های ذخیره‌شده» شما نمایش داده می‌شود (قابل تنطیم با `STEALTH_CONFIRM`).

<div dir="rtl">

| کد مخفی | محدوده | عملکرد |
| :--- | :---: | :--- |
| `777` | چت جاری | **روشن کردن رفیق** با پرسونای پیش‌فرض. |
| `777 <persona>` | چت جاری | **رفیق با لحن خاص** (مانند `777 sarcastic`). |
| `000` / `000 all` | چت / سراسری | **خاموش کردن رفیق**. |
| `777 engage [دقیقه]` | گروه | **تعامل خودکار** (پیش‌فرض هر ۲۰ دقیقه). |
| `777 engage auto` | گروه | 🧠 **تعامل هوشمند**: سرعت گروه را می‌سنجد و فاصله را برای حضور حدود ۵٪ تنطیم می‌کند. |
| `777 engage off [all]` | گروه / سراسری | **خاموش کردن تعامل خودکار**. |
| **`666`** | **فقط همین چت** | 🆕 **روشن کردن دستیار فقط در چت جاری**. |
| **`666 all`** | **تمام پیوی‌ها** | **دستیار برای همهٔ پیوی‌ها** (فعلی و آینده). معادل‌ها: `666 کل`، `666 همه`. |
| `444` | چت جاری | **توقف دستیار فقط در این چت**. |
| `444 all` / `444 کل` | تمام پیوی‌ها | **خاموش کردن کامل دستیار**. |
| `!مسدود` (روی پیام) | سراسری | **لیست سیاه**: دستیار دیگر هرگز به این کاربر جواب نمی‌دهد (`!مسدود 123456` هم قبول است). |
| `!آزاد` (روی پیام) | سراسری | **حذف کاربر از لیست سیاه**. |
| `!استیکر <توضیح>` | سراسری | 🎭 **آموزش استیکر**: روی استیکر ریپلای کن و معنی‌اش را بگو. |
| `!استیکر لیست` / `!استیکر حذف` | سراسری | 🎭 مدیریت استیکرهای آموزش‌دیده. |
| `222 [ساعت]` | گروه/پیوی | **خلاصه گفتگو**: اتفاقات ۱۲ ساعت گذشته (تا ۷۲ ساعت) + پیام‌های منتطر جواب. |
| `112 <سوال>` | هرجا | **جستجوی وب** با گوگل (قیمت ارز، آب‌وهوا، اخبار). |
| `111 [دستور]` | ریپلای | **پاسخ هوشمند** به پیام ریپلای‌شده. |
| `555 <یادآور>` | چت جاری | **یادآور هوشمند**: `555 ساعت 21 به علی بگو تماس بگیره`. |
| `333` | چت جاری | **ریست حافطه** کوتاه‌مدت و بلندمدت. |
| `999 [تعداد]` | چت جاری | **پاکسازی روح**: حذف همه (یا N پیام آخر) پیام‌های شما. |
| `555` | چت جاری | **وضعیت زنده** با حذف خودکار. |
| `888` | چت جاری | **راهنما** و لیست کدهای مخفی. |

### 🔔 بازخورد مخفی و گزارش خطا

- تأیید همهٔ دستورها به «پیام‌های ذخیره‌شده» می‌رود و خودبه‌خود پاک می‌شود — هیچ ردی در چت مقصد نمی‌ماند.
- خطاهای موتور یا ارسال هم به همانجا گزارش می‌شوند؛ دیگر هیچ خطایی بی‌صدا گم نمی‌شود (`NOTIFY_ERRORS=0` برای غیرفعال کردن).

### 👁️ درک چندرسانه‌ای

وقتی حالت «رفیق» (`777`) یا «دستیار» (`666`) فعال باشد:

- 📷 **عکس** → محتوای عکس تحلیل می‌شود و طبیعی جواب می‌دهد.
- 🎙️ **ویس** → صدا شنیده و فهمیده می‌شود.
- 🎬 **ویدیونوت و ویدیو** → محتوای ویدئو دیده می‌شود (تا ~۱۸ مگابایت).
- 📄 **PDF و فایل متنی** → محتوای فایل خوانده و تحلیل می‌شود.

*(یادآورها در `reminders_state.json` ذخیره می‌شوند و با ری‌استارت از بین نمی‌روند.)*

## 🎯 دامنهٔ دستیار: `666` یا `666 all`

<div dir="rtl">

قبلاً دستیار یا در همه‌جا روشن بود یا هیچ‌جا. حالا **دو لایه** دارد تا بتوانی منشی را فقط برای یک نفر خاص بگذاری بدون اینکه همهٔ پیوی‌هایت درگیر شوند.

| دستور | نتیجه |
|---|---|
| `666` | دستیار **فقط در همان چتی که فرستادی** روشن می‌شود. |
| `666 all` | دستیار برای **تمام پیوی‌ها** روشن می‌شود، شامل کسانی که بعداً پیام می‌دهند. |
| `666 <چیز دیگر>` | با هشدار رد می‌شود — یک غلط تایپی هرگز تو را بی‌سروصدا به حالت سراسری نمی‌برد. |
| `444` | دستیار در این چت ساکت می‌شود (و از لیست چت‌های فعال حذف می‌شود). |
| `444 all` | دستیار کاملاً خاموش می‌شود: حالت سراسری، لیست چت‌ها و سکوت‌ها پاک می‌شوند. |

داشبورد `555` دقیقاً می‌گوید کدام لایه فعال است و چند چت تک‌به‌تک روشن شده‌اند.

> [!WARNING]
> **مهاجرت یک‌باره.** فایل‌های وضعیتی که قبل از این تغییر نوشته شده‌اند در اولین اجرا ارتقا می‌یابند و دستیار **خاموش** می‌شود تا بی‌سروصدا به همهٔ پیوی‌ها جواب ندهد. بعد از آپدیت، در چت‌هایی که می‌خواهی `666` بزن یا یک‌بار `666 all` بفرست. لیست سیاه و چت‌های ساکت‌شده دست‌نخورده می‌مانند.

</div>

## 🎭 حالت‌های هوش مصنوعی و پرسونای پویا

<div dir="rtl">

### ۱. حالت رفیق (Alter-Ego)
با کد `777` ربات درست مثل خود شما رفتار می‌کند؛ لحن عامیانه، پاسخ‌های کوتاه بدون ایموجی و ارجاع دقیق به سوابق گفتگو. در گروه‌ها تنها وقتی جواب می‌دهد که روی شما ریپلای بزنند یا منشنتان کنند.

### ۲. حالت دستیار شخصی
با `666` برای یک چت و با `666 all` برای همهٔ پیوی‌ها فعال می‌شود. نقش منشی موقر شما را بازی می‌کند، به مراجعین پاسخ محترمانه می‌دهد و پیام می‌گیرد.

### ۳. تعامل خودکار در گروه‌ها (Auto-Engage)
با `777 engage <دقیقه>` ربات سوابق گروه را هر چند دقیقه یک‌بار بررسی می‌کند و اگر بحث جالبی در جریان باشد، هوشمندانه وارد می‌شود. با `777 engage auto` فاصله را خودش بر اساس سرعت واقعی گروه انتخاب می‌کند.

### ۴. تعویض زندهٔ پرسوناها
کافیست هر فایل `.txt` را درون پوشهٔ `personas/` قرار دهید:

```
personas/
├── normal.txt          <- لحن عامیانه و پیش‌فرض
├── assistant.txt       <- لحن منشی محترمانه
├── sarcastic.txt       <- لحن طعنه‌زن و تیکه‌دار
├── poetic.txt          <- لحن شاعرانه و دراماتیک
├── academic.txt        <- لحن رسمی و علمی
├── angry.txt           <- لحن عصبی و رک
├── drunk.txt           <- لحن صمیمی و بی‌فیلتر
└── lust.txt            <- لحن محبت‌آمیز و دلنشین
```

> [!TIP]
> برای لحن جدید کافیست فایلی مانند `personas/gamer.txt` بسازید و با `777 gamer` فعالش کنید — بدون ریستارت!

## ⚡ شبیه‌ساز رفتار انسانی

<div dir="rtl">

بزرگ‌ترین نشانهٔ روبات بودن یک یوزربات این نیست که *چه* می‌نویسد؛ این است که *چقدر سریع* می‌نویسد. یک پاراگراف ۴۰۰ کاراکتری که بعد از ۳ ثانیه بیاید، برای انگشت انسان غیرممکن است. پس کل خط لولهٔ ارسال انسانی‌سازی شده است:

۱. **تاخیر خواندن متناسب** پیش از شروع تایپ، تا واقعاً مثل خواندن پیام به نطر برسد.
۲. **زمان تایپ متناسب با طول متن** روی منحنی غیرخطی، با سقف **۴۵ ثانیه** جای سقف خشک ۷ ثانیه‌ای قدیم.
۳. **مکث‌های تصادفی فکر کردن** در میانهٔ تایپ، تا علامت typing درست مانند انسان روشن و خاموش شود.
۴. **تکه‌تکه فرستادن خودکار**: جواب‌های بلندتر از آستانه از مرز جملات بریده و به صورت **چند پیام جداگانه** با تایپینگ کوتاه بینشان فرستاده می‌شوند. کد و استیکر هرگز تکه نمی‌شوند.
۵. **پالایشگر خروجی ضد ربات**: حذف ایموجی، اعراب عربی، تگ‌های HTML و لیست‌های مارک‌داون پیش از ارسال.

**زمان‌بندی تقریبی:**

| طول جواب | زمان تایپ |
|---|---|
| ~۵ کاراکتر | ~۱.۲ ثانیه |
| ~۵۰ کاراکتر | ~۱۵ ثانیه |
| ~۱۵۰ کاراکتر | ~۵۰ ثانیه (تکه‌تکه می‌شود) |
| بیش از ۴۰۰ کاراکتر | سقف ۴۵ ثانیه برای هر حباب |

تمام این اعداد با متغیرهای `HUMAN_*` قابل تنطیم‌اند.

</div>

## 🧬 حافطه دو لایه

<div dir="rtl">

- **حافطه کوتاه‌مدت**: واکشی ۳۰ پیام اخیر با ساختار فرستنده، زمان و رشتهٔ ریپلای‌ها.
- **خلاصه‌ساز بلندمدت پس‌زمینه**: هر ۳۰ پیام، مهم‌ترین فکت‌ها فشرده و در `memory_state.json` ذخیره می‌شوند.
- **ریست آنی حافطه (`333`)**: کلیهٔ سوابق کوتاه‌مدت و خلاصهٔ بلندمدت آن چت فوراً پاک می‌شود.

## 🛡️ موتور مدیریت کلیدهای جمینای

<div dir="rtl">

- **چرخش خودکار کلیدها (Round-Robin)**: تعداد نامحدود کلید در `apis.txt` یا `.env`.
- **سقف دلخواه هر مدل**: با `GEMINI_MODELS="name:rpm:rpd,..."` و پیش‌فرض‌های `DEFAULT_MODEL_RPM` / `DEFAULT_MODEL_RPD`.
- **شمارنده سهمیه روزانه**: ثبت مصرف هر کلید در `api_usage.json` با سقف ایمن زیر حد گوگل.
- **Circuit Breaker**: کلیدی که ۳ بار پیاپی خطا بدهد، ۳ ساعت قرنطینه می‌شود.
- **تایم‌اوت سخت**: `GEMINI_TIMEOUT` و بازهٔ طولانی‌تر `SEARCH_TIMEOUT` برای جستجوی وب.

## 🚀 راه‌اندازی و نصب سریع

<div dir="rtl">

### روش اول: Railway (پیشنهادی برای اجرای ۲۴ ساعته)

۱. این ریپو را فورک/کلون کنید و یک سرویس Railway از روی آن بسازید.
۲. یک **Volume** بسازید و در مسیر `/app/data` وصل کنید — بدون آن، حافطه، یادآورها و وضعیت مودها با هر ری‌استارت پاک می‌شوند.
۳. `python3 gen_session_string.py` را **روی سیستم خودتان** اجرا کنید و خروجی را در `SESSION_STRING` بگذارید.
۴. متغیرهای `API_ID`، `API_HASH`، `GEMINI_API_KEYS`، `OWNER_ID` را تنطیم کنید.
۵. دیپلوی کنید. لاگ اولیه وضعیت رفیق/دستیار و لیست کدهای فعال را چاپ می‌کند.

> [!TIP]
> اگر Railway خطای **«GitHub Repo not found»** نشان داد، یعنی اپ Railway دسترسی‌اش به ریپو را از دست داده. به <https://github.com/settings/installations> بروید ← Railway ← دسترسی به این ریپو را بدهید، سپس Source Repo را قطع و وصل کنید و Redeploy بزنید.

### روش دوم: ویزارد نصب آسان (ویندوز)

```powershell
# روی setup.bat دوبار کلیک کنید یا:
python setup.py
```

### روش سوم: نصب دستی و محلی (CLI)

```bash
git clone https://github.com/parhambepe/ghostali.git
cd ghostali
python -m venv venv
source venv/bin/activate   # در ویندوز: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
python login.py
python main.py
```

### روش چهارم: اجرا با داکر

```bash
docker compose up -d --build
docker compose logs -f
```

### روش پنجم: استقرار ۲۴ ساعته روی سرور لینوکس (VPS)

اسکریپت‌های `deploy.bat` و `deploy.sh` پروژه را بسته‌بندی کرده، روی سرور آپلود نموده و به عنوان سرویس `systemd` اجرا می‌کنند. کافیست در `.env` مقادیر `VPS_IP`، `SSH_USER`، `SSH_PORT` را وارد کنید و اسکریپت را اجرا نمایید؛ پروژه روی `/opt/ghostgram` مستقر می‌شود.

## 💾 فایل‌های وضعیت و مهاجرت

<div dir="rtl">

تمام وضعیت ربات در مسیر `DATA_DIR` (روی Railway: `/app/data`) ذخیره می‌شود:

| فایل | محتوا |
|---|---|
| `assistant_state.json` | دامنهٔ دستیار (فلگ سراسری + لیست چت‌ها)، سکوت‌ها، لیست سیاه |
| `pal_state.json` | چت‌های حالت رفیق، پرسوناها، زمان‌بندی تعامل خودکار |
| `memory_state.json` | حافطهٔ بلندمدت فشردهٔ هر چت |
| `reminders_state.json` | یادآورهای در انتطار |
| `stickers_state.json` | استیکرهای آموزش‌دیده و معنایشان |
| `api_usage.json` | شمارندهٔ مصرف روزانهٔ هر کلید |

فایل‌های وضعیت **نسخه‌دار** هستند. وقتی ساختارشان تغییر کند، در اولین اجرا مهاجرت می‌کنند و تغییر در لاگ اعلام می‌شود. مهاجرت‌ها همیشه **محافطه‌کارانه** عمل می‌کنند — در صورت شک، یک مود **خاموش** می‌شود نه اینکه بی‌سروصدا فعال بماند.

</div>

## 🗺️ نقشهٔ راه

<div dir="rtl">

ایده‌هایی که در دست بررسی اند:

- **ساعات خواب** — ربات شب‌ها خاموش شود تا مثل ماشین ساعت ۴ صبح جواب ندهد.
- **شبیه‌سازی حضور** — الگوی واقعی‌تر آنلاین/آفلاین و «آخرین بازدید».
- **پرسونای اختصاصی هر مخاطب** — لحن رسمی با همکار، لحن خودمانی با دوست.
- **تشخیص تحویل به انسان** — وقتی گفتگو به خود شما نیاز دارد، جای بافتن جواب، به شما اطلاع دهد.
- **پاسخ صوتی** — جواب دادن به ویس با ویس ساختگی.
- **حالت تأیید پیش‌نویس** — ربات جواب را در «پیام‌های ذخیره‌شده» پیشنهاد می‌دهد و فقط با تأیید شما می‌فرستد.
- **گزارش هفتگی** — خلاصهٔ خودکار اینکه کی پیام داد و دستیار چه جوابی داد.
